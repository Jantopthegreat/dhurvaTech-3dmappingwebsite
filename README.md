cara melihat branch 
git branch

melihat updatean dari branch
git fetch

lalu untuk menyesuaikan code dengan yang terbaru 
git pull origin (sesuai nama branch)

lalu sesuaikan conflict jika ada

dan jika ingin push push di branch jangan langsung dimain
caranya sama seperti pull

cek dulu kau sedang di branch mana 
caranya git branch juga tapi lokasi branch kau ada tanda bintang (*)
    * feat/admin
    main
kek ini 

commit terlebih dahulu, lalu push di branch kau

contoh:
git push origin feat/frontend_ayamcemani
